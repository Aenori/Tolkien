# 1.6 — Faits ajoutés par l'IA dans les slides

Ce dossier liste les faits (dates, noms, lieux, publications…) que l'IA a mis dans
`2-slides/slides.md` alors qu'ils ne figurent pas dans `1-brief/`.

- L'arborescence reproduit celle de `1-brief/` : les faits ajoutés à partir de
  `1-brief/textes/02-vie.md` sont dans `textes/02-vie.md` ici.
- Chaque fait indique la slide concernée et sa source, ou **[IA, à vérifier]**.
- Une fois un fait vérifié, le reporter dans `1-brief/` et le retirer d'ici.
