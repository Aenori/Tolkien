# 1.5 — Propositions de l'IA

Ce dossier contient des propositions de contenu rédigées par l'IA, à partir de ses
connaissances et des sources du dépôt (`sources/`).

- Ce n'est **pas** une source de vérité : rien ici n'est repris dans les slides tant que
  l'auteur ne l'a pas validé et reporté dans `1-brief/` (textes, plan, citations).
- Chaque fait indique sa source. Ce qui vient uniquement des connaissances de l'IA est
  marqué **[IA, à vérifier]**.
- Les citations proposées ne sont pas utilisables telles quelles : les vérifier, puis les
  ajouter à `1-brief/citations.md`.
